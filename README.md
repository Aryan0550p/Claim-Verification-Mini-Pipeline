# Fractiva Claim Verification Pipeline

A mini claim-verification pipeline that checks pharma marketing claims against cited clinical studies.

## Setup (5 commands or fewer)

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Set your API key (Gemini or OpenAI)
$env:GEMINI_API_KEY = "your-key-here"      # Windows PowerShell
# OR
export GEMINI_API_KEY="your-key-here"      # macOS/Linux bash

# 3. Run the verifier
python verify.py data/claims.json

# 4. Run the evaluator
python eval.py
```

> **Note**: If no API key is set, `verify.py` exits cleanly and returns `cannot_verify` for all claims. It never crashes or returns `supported` without evidence.

## Project Structure

```

├── eval.py                      # Evaluation script
├── requirements.txt             # Pinned dependencies
├── data/
│   ├── claims.json              # 7 claims to verify (given)
│   └── gold.json                # Hand-written gold answers
├── papers/
│   ├── SoliMix_Rosenstock2021.pdf       # C2, C4, C6, C7
│   ├── LixiLan-O_Rosenstock2016.pdf     # C3
│   ├── LixiLan-L_Aroda2016_abstract.pdf # C5, C7
│   └── Tabak2020_PSM.pdf                # C7
├── outputs/
│   ├── predictions.json         # Generated by verify.py
│   └── llm_log.jsonl            # All LLM calls logged
└── WRITEUP.md                   # Analysis writeup
```

## How it works

1. **PDF extraction**: PyMuPDF extracts text from all cited papers
2. **LLM analysis**: Gemini (or OpenAI) reads the source text and identifies evidence spans (verbatim)
3. **Python arithmetic**: All number comparisons (ratios, differences, ORs) are computed in Python — the LLM only locates numbers
4. **Fail-closed logic**: Any mismatch, silence, or ambiguity → `cannot_verify`. A correct `cannot_verify` is a right answer.
5. **Full logging**: Every LLM prompt + response is appended to `outputs/llm_log.jsonl`

## Supported LLM Backends

| Backend | Key env var | Model |
|---------|------------|-------|
| Google Gemini | `GEMINI_API_KEY` or `GOOGLE_API_KEY` | gemini-2.0-flash |
| OpenAI | `OPENAI_API_KEY` | gpt-4o-mini |

Free-tier Gemini keys work fine.
